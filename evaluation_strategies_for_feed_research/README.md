# Researching evaluation strategies for Convictional Feed

**Authors:** Matt Chequers, Adam McCabe

This "experiment" is a log of research done related to potential evaluation strategies for the Convictional Feed.

Basically, this directory holds information related to best practices in the community and how feed-related algorithms are evaluated.

The GitHub issue, the internal discussion post, and the human-written summary doc that accompanied
this work are all internal and are not public.

Much of the background reading came from the book *Practical Recommender Systems* (Kim Falk,
Manning). It is not redistributed here.

The research notes are in the subdirectory `detailed_experiment_notes/`, and each notes file aims at answering specific questions:
1. High level: How are recommender feeds evaluated?
2. Does the evaluation method depend on which algorithm we build?
3. Recommender algorithm evaluation methods, in detail
4. Context and timing dependence in recommender evaluations ("right item, wrong moment")
5. Modaic & "confidence" scores for LLM-as-a-Judge

The directory `claude_notes` holds notes that a Claude agent can read and immediately get up to speed on the work, and continue where the experiment left off.
