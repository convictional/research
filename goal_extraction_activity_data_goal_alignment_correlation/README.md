# Overview

> **Data availability:** All input, intermediate, and output data for this experiment
> (`src/data/`) was a verbatim production export containing meeting summaries, personal data, and
> expert-rater annotations keyed to named individuals. **It was removed before open-sourcing.**
> The analysis code ships as-is and describes the schema it expects, but the experiment cannot be
> reproduced from this repository. The charts and rater-agreement figures are likewise not included.

This analysis is for testing how different types of activity data correlate with understanding goal alignment.

This is an extension of the original goal extraction research prototype work. In particular, this experiment focuses on step 2 of that goal extraction process - mining activity data for goals.

Thus, this analysis largely boils down to finding types of activity data that produce accurate extracted (unstated) goals.

The Convictional Task for this analysis is [internal app task, not public].
