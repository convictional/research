# Overview

This experiment/research bet is related to linking (external) "tasks" to goals in Convictional.

The app task for this experiment is found [internal app task, not public].

Paraphrased on that task's description:

- Main question: "How possible is it to link task objects from external systems to goals in Convictional?"
- This could be similar to the SRED project extraction work we did, but instead of the LLM coming up with its own category groupings for projects, we woudl anchor to the goals in Convictional
- Keep our "suggested links" ability in mind for this bet
- For an experiment, could use our own goals:
    - Could use tasks within the app, and external task objects like GitHub issues and PRs, as input task objects
    - Note, tasks/GitHub issues/PRs/etc don't necessarily HAVE TO link to a goal - we only want to link if it makes sense to do so
    - Also note, a task object can link to multiple goals
