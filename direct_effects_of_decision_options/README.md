# Overview

**Authors:** Matt Chequers, Adam McCabe

This experiment is for finding "Direct effects" of decision options using an LLM.

By "direct effects", we mean direct cause and effect relations - that is, cause and effects that are very likely given a decision option.

The issue for this experiment is #2089 (internal GitHub issue, not public).

# Results

A Google doc outlining the methods and results for this experiment exists internally and is not public.

The results were posted as a comment on the main internal GitHub issue for named entity knowledge store direct effects; that issue is not public.
